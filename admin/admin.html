Prepara gli articoli qui e segui i passaggi per pubblicarli sul magazine.

Pubblicare un aggiornamento
  1. Modifica o aggiungi gli articoli: le bozze restano in questo browser.
  2. Seleziona Scarica articles.json.
  3. Sostituisci data/articles.json nel progetto con il file scaricato; aggiungi anche le nuove immagini in assets/images/.
  4. Controlla il sito in locale, poi salva e invia le modifiche al repository per pubblicarle su GitHub Pages.
Il pannello non modifica i file del progetto e non pubblica direttamente. Dopo la pubblicazione, conserva il JSON aggiornato come base per le prossime modifiche.
